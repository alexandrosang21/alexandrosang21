# Alexander Angelov

Full-stack developer based in Greece. I build web apps with TypeScript, Next.js, React Native and Astro, and browser games on the side — usually end to end, from schema to deploy.

Portfolio and CV: **[cv.angelov.gr](https://cv.angelov.gr)**

## Projects

**[island-survival](https://github.com/alexandrosang21/island-survival)** · [play it](https://forest.angelov.gr)  
A 3D survival game that runs entirely in the browser. Gather and craft, build a shelter across two storeys, hunt wildlife, and hold your base through raid nights. Three.js, Rapier physics and TypeScript on Vite.

**[lagokefalos-escape](https://github.com/alexandrosang21/lagokefalos-escape)** · [play it](https://lagokefalos-escape.vercel.app)  
Endless lane-runner on the Aegean with a national leaderboard, a daily seeded challenge, and generated share cards. Next.js, canvas, Drizzle and Postgres — no login anywhere, players are an anonymous cookie.

**[obistart](https://github.com/alexandrosang21/obistart)** · [try it](https://obistart.vercel.app)  
Minimal, distraction-free browser start page with daily goals. Next.js 16, React 19 and Tailwind 4.

**[projextXgameroom](https://github.com/alexandrosang21/projextXgameroom)**  
Realtime multiplayer games to play with colleagues — arena fighter, shared piano, tic-tac-toe — all running over a single Socket.IO server. Next.js 16 and Tone.js.

I also work on private projects: an ASO keyword intelligence tool, an expense-splitting mobile app (Expo + Next.js monorepo), and an AI chatbot builder for Greek businesses.

## Stack

TypeScript · React · Next.js · Expo · Astro · Three.js · Tailwind · Node.js · PostgreSQL · Drizzle · Prisma · Docker
